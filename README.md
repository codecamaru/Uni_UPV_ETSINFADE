## Intelligent Systems

Labs and exercises in knowledge-based systems and neural networks as part of the **Intelligent Systems** module.

- **CLIPS Rule-Based Expert Systems** — Implemented expert system rules in CLIPS for DNA mutation analysis (`MutacionesADN.CLP`), street lamp placement optimisation (`farolas.CLP`), and generic intelligent problem solving (`ejers.CLP`).
- **Perceptron** — From-scratch single-layer perceptron implementation in Python.

**Topics:** Propositional logic, forward chaining, rule-based inference, binary classification.

---

## Parallel Computing

High-performance computing projects using **MPI** and **OpenMP** for distributed-memory and shared-memory parallelism.

- **MPI** — Message Passing Interface programs for distributed computation across cluster nodes.
- **OpenMP** — Shared-memory parallel programs using compiler directives for loop-level and task-level parallelism.

**Topics:** Race conditions, synchronisation, load balancing, speedup and efficiency analysis.

## Concurrency

Concurrent and distributed systems implemented in **Java**, exploring classic concurrency problems and distributed messaging architectures.

- **Ants Simulation** — Multi-agent concurrent simulation of ant colony behaviour.
- **Dining Philosophers (PPhilo)** — Classic synchronisation problem implementation with deadlock avoidance.
- **Thread Pool (PPool)** — Producer-consumer thread pool with task scheduling.
- **Distributed Chat via JMS** — A publish-subscribe chat system using Java Message Service.
- **Distributed Chat via RMI** — A remote method invocation-based distributed chat application.

**Topics:** Mutual exclusion, monitors, semaphores, publish-subscribe, remote invocation.
